# CPA 知识库问答系统 - 项目架构

## 一、项目定位

一个**CPA考试辅导问答系统**，使用 RAG（检索增强生成）技术：
- 将23本 CPA 教材 PDF → Markdown → **向量化存入 PostgreSQL**
- 用户提问时：**向量检索**教材知识库 + **DeepSeek API** 生成回答
- Web界面 + Socket.IO 流式输出 + 知识库管理后台

## 三、核心文件详解

### 3.1 🚀 `web_app.py` — 主服务（最核心）

| 功能 | 说明 |
|------|------|
| **Web服务** | Flask + Socket.IO，端口5000 |
| **Embedding模型** | `qwen3-embedding:8b` → 4096维向量 |
| **流式回答** | Socket.IO `stream_answer` 事件逐字推送 |
| **双库检索** | 教材知识库(`cpa_embeddings`) + 历史问答(`cpa_qa_history`) |
| **问答存储** | 每次回答自动保存到 `cpa_qa_history`（含引用来源ID） |
| **管理API** | `/admin` 管理页面 + 8个REST API |
| **技能系统** | 知识库检索 / 历史问答检索 / 计算器 / 思考模式 |

### 3.2 📥 `import_all_cpa_8b.py` — 教材导入脚本（主推版本）

| 功能 | 说明 |
|------|------|
| **三阶段流水线** | 1️⃣收集章节 2️⃣异步向量化 3️⃣批量写入DB |
| **Embedding** | asyncio + aiohttp 异步请求 Ollama，10并发 |
| **模型** | `qwen3-embedding:8b` → 4096维 |
| **写入方式** | 手动事务 + `execute_values` 每1000条批量 INSERT |
| **数据过滤** | 过滤 <50字符的碎片（封面、图片引用、公式碎片等） |
| **内容解析** | 以 `#章`/`##节` 为界分割，不按空行切分，避免碎片化 |
| **数据清洗** | 自动清除 `【图片：xxx】` 和 `$$...$$` LaTeX公式标记 |

**配套文件**：`import_all_cpa.py`（旧版0.6b模型，1024维，已归档）

### 3.3 🖥️ `templates/index.html` — 前端页面

| 功能 | 说明 |
|------|------|
| **Socket.IO** | 实时接收流式回答 + 打字状态 |
| **Markdown渲染** | marked.js 渲染回答 |
| **双库展示** | 📚 教材 / 📋 历史问答，图标+来源名称区分 |
| **思考过程** | 橙黄背景展示reason模型的推理过程 |

## 四、数据库结构

### 4.1 当前表

| 表名 | 用途 | 关键字段 |
|------|------|---------|
| **cpa_embeddings** | 📚 教材知识库(向量) | `source_type`, `source_id`, `chunk_content`, `chunk_summary`, `metadata`(JSONB), `embedding`(VECTOR(4096)) |
| **cpa_qa_history** | 📋 历史问答(向量) | `question`, `answer`, `combined_content`, `embedding`(VECTOR(4096)), `metadata`(JSONB) |
| **cpa_courses** | 科目表 | `course_code`, `course_name` |
| **cpa_books** | 教材表 | `book_name`, `book_type`, `course_id` |
| **cpa_chapters** | 章节表 | `chapter_number`, `chapter_title`, `md_content`, `book_id` |
| **cpa_knowledge_points** | 知识点（预留） | - |
| **cpa_qa_pairs** | 真题问答（预留） | - |

### 4.2 向量维度说明

| 模型 | 维度 | 适用脚本 |
|------|:----:|---------|
| `qwen3-embedding:8b` | **4096** | `import_all_cpa_8b.py` ✅ 当前使用 |
| `qwen3-embedding:0.6b` | 1024 | `import_all_cpa.py`（旧版） |

> ⚠️ 切换模型需同时修改数据库字段：`python change_vector_dimension.py <维度>`
> 该脚本会同步更新 `cpa_embeddings` 和 `cpa_qa_history` 两张表的 `embedding` 列

## 五、数据流

```
教材PDF → OCR → Markdown → import_all_cpa_8b.py
                                    │
                                    ▼ [parse_markdown_content]
                                cpa_chapters (章节)
                                    │  - 以 #章 / ##节 为界分割
                                    │  - 不按空行切分
                                    │  - 过滤 <50字符碎片
                                    │  - 清除图片/公式标记
                                    ▼ [create_chunks 切分 600字+100重叠]
                                文本块列表
                                    │
                                    ▼ [Ollama qwen3-embedding:8b]
                                4096维向量 (10并发)
                                    │
                                    ▼ [execute_values 批量写入]
                                cpa_embeddings (每1000条commit一次)
                                    
用户提问 → web_app.py
    │
    ├─→ search_knowledge_base() → cpa_embeddings 向量检索
    ├─→ search_qa_history()     → cpa_qa_history  向量检索
    │
    ▼ [拼接上下文]
    DeepSeek API → 流式回答 → Socket.IO → 前端显示
    │
    ▼ [自动保存]
    save_qa_history() → cpa_qa_history (含引用来源)
```

## 八、启动方式


## 十、常见问题排查

| 问题 | 排查方向 |
|------|----------|
| 知识库检索无结果 | 检查 `cpa_embeddings` 是否有数据 |
| 向量维度错误 | `embedding` 列定义和模型维度需一致 |
| Ollama连接失败 | `ollama serve` 是否在运行 |
| 搜索质量差 | 数据是否太碎片？运行 `python check_data_quality.py` |
| 导入无输出 | async embedding 可能静默失败，检查 Ollama 日志 |
| 管理页面数据0 | 运行 `clear_embeddings.py` 后需重新导入 |
