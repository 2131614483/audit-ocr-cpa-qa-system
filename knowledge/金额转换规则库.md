## 二、金额转换规则

### 2.1 转换基本规则

#### 规则1：个位数转换
```
一元 → 1元
贰元 → 2元
叁元 → 3元
...
玖元 → 9元
```

#### 规则2：十位数转换
```
壹拾元 → 10元
贰拾元 → 20元
叁拾元 → 30元
...
玖拾元 → 90元

特殊情况：
十五元 → 15元（非壹拾伍元）
贰拾壹元 → 21元
```

#### 规则3：百位数转换
```
壹佰元 → 100元
贰佰元 → 200元
...
玖佰元 → 900元

壹佰零叁元 → 103元
壹佰叁拾元 → 130元
```

#### 规则4：千位数转换
```
壹仟元 → 1000元
贰仟元 → 2000元
...
玖仟元 → 9000元

壹仟零佰元 → 1000元
壹仟叁佰元 → 1300元
```

#### 规则5：万位数转换
```
壹万元 → 10000元
贰万元 → 20000元
...
玖万元 → 90000元

壹万叁仟元 → 13000元
壹万叁仟肆佰元 → 13400元
```

### 2.2 带小数金额转换

#### 规则6：角分转换
```
壹元叁角 → 1.30元
贰元伍角 → 2.50元
叁元柒角 → 3.70元

壹元叁角肆分 → 1.34元
贰元伍角陆分 → 2.56元
```

#### 规则7：整数元转换（无角分）
```
壹佰元整 → 100.00元
贰仟元整 → 2000.00元
叁万元整 → 30000.00元
```

### 2.3 复杂金额转换示例

#### 示例1：标准转换
```
壹仟贰佰叁拾肆元伍角陆分
= 1000 + 200 + 30 + 4 + 0.5 + 0.06
= 1234.56元
```

#### 示例2：带零转换
```
壹仟零佰叁拾元整
= 1000 + 0 + 30
= 1030.00元
```

#### 示例3：万为单位大金额
```
叁拾伍万元整
= 350000.00元
```

#### 示例4：亿为单位超大金额
```
贰亿叁仟肆佰伍拾陆万柒仟捌佰玖拾元
= 200000000 + 34567000 + 890
= 234567890.00元
```

#### 示例5：繁体简体混合
```
壹萬伍仟元 → 15000.00元
叁亿肆仟万元 → 340000000.00元（注意：叁亿肆仟万 = 3.4亿）
```

## 四、风险金额识别规则

### 4.1 异常金额阈值

| 票证类型 | 合理金额范围 | 异常阈值 |
|---------|-------------|---------|
| 出租车票 | 10-200元 | 超过500元需复核 |
| 火车票 | 50-1500元 | 超过2000元需复核 |
| 飞机票 | 200-3000元 | 低于100元或超过10000元需复核 |
| 餐费发票 | 50-1000元 | 超过3000元需复核 |
| 办公用品 | 100-5000元 | 超过20000元需复核 |
| 差旅费合计 | 500-10000元 | 超过50000元需复核 |

### 4.2 风险金额模式

#### 模式1：临界值规避
```
金额刚好为 9999.99元 → 规避10000元审批权限
金额刚好为 99999.99元 → 规避100000元审批权限
```

#### 模式2：整数偏好
```
金额为 10000元、20000元等整数 → 可能存在凑票报销
```

#### 模式3：零头金额
```
金额为 9999.99元、8888.88元等特殊数字 → 可能存在虚增金额
```

## 五、金额校验规则

### 5.1 发票金额校验

#### 规则1：价税合计校验
```
价税合计 = 金额 + 税额

示例：
金额：1000.00元
税率：13%
税额：130.00元
价税合计：1130.00元

校验：|价税合计 - (金额 + 税额)| < 0.01元
```

#### 规则2：发票金额大写小写一致性
```
大写：壹仟壹佰叁拾元整
小写：1130.00元

校验：大写金额 == 小写金额
```

### 5.2 行程单金额校验

#### 规则3：机票票价构成
```
合计金额 = 票价 + 民航发展基金 + 燃油附加费

示例：
票价：880.00元
民航发展基金：50.00元
燃油附加费：120.00元
合计金额：1050.00元

校验：合计 == 票价 + 50 + 燃油费
```

### 5.3 火车票金额校验

#### 规则4：票价合理性
```
票价应与里程和席别相匹配

示例：
北京到上海高铁二等座：
- 里程：约1318公里
- 票价范围：约553-600元

校验：票价应在合理范围内
```
